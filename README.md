# 🚗 Vehicle Service Management Application

### Pega National Internship Program | Capstone Project

> A structured and automated vehicle service management solution built using the **Pega Platform (App Studio)** for **Urban Fleet Operations**.

---

## 📌 Overview

Urban Fleet Operations previously handled vehicle service requests through **emails and phone calls**. This manual process made it difficult to track requests, monitor service progress, coordinate approvals, and maintain service information efficiently.

The **Vehicle Service Management Application** replaces this manual approach with a centralized and automated **Pega case management solution**.

The application provides a structured workflow from **service request creation to final resolution**.

---

## 🎯 Project Objectives

The main objectives of this application are to:

- 🚗 Simplify vehicle service request management
- 📋 Provide structured service request tracking
- 🔍 Support vehicle inspection and assessment
- 💰 Generate and manage service estimates
- ✅ Capture customer approval before service execution
- 👨‍🔧 Support technician assignment and service management
- 🔄 Automate the service request lifecycle
- ⏱️ Improve service monitoring and operational efficiency
