# 🚗 Vehicle Service Management Application

## Pega National Internship Program – Capstone Project

A Vehicle Service Management Application developed using the **Pega Platform (App Studio)** for **Urban Fleet Operations**.

---

## 📌 Project Overview

Urban Fleet Operations previously handled vehicle service requests through emails and phone calls, making it difficult to track requests and manage the complete service lifecycle.

This application replaces the manual process with a structured and automated **Pega case management system**.

The application improves:

- Service request tracking
- Service visibility
- Process automation
- Customer approval management
- Operational efficiency
- End-to-end service lifecycle management

---

## 🎯 Project Objective

The objective of this project is to provide a centralized application where vehicle service requests can be created, assessed, approved, executed, and completed through an automated workflow.

---

## 🛠️ Technology Used

- **Platform:** Pega Platform
- **Development Environment:** Pega App Studio
- **Application Type:** Case Management Application

---
