# Project Technical Details

## Application Information

**Application Name:** NIP-VehicleService-Divyadharshini

**Case Type:** Vehicle Service Request

**Platform:** Pega Platform – App Studio

**Program:** Pega National Internship Program

**Organization:** Urban Fleet Operations

---

# Project Problem

Vehicle service requests were previously raised through emails and phone calls.

This manual approach created challenges in:

- Tracking service requests
- Managing service progress
- Maintaining service information
- Coordinating approvals
- Providing service visibility

The Pega application was developed to provide a structured and automated solution.

---

# Application Lifecycle

The application follows five main stages:

1. Request Intake
2. Service Assessment
3. Customer Approval
4. Service Execution
5. Completion & Resolution

---

# Implemented Features

- Vehicle Service Request Submission
- Vehicle Inspection
- Service Estimate Generation
- Customer Approval
- Vehicle Data Management
- Case Review and Resolution
